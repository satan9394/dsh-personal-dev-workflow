# runstate-cli — 项目本地规则

- 技术栈：Node ≥18，**零依赖**（只用 `node:` 内置模块）；单文件 CLI。
- 入口：`runstate.js`；不得拆成多包、不得引入 package.json 依赖。
- 状态：`RUN_STATE.md` 是唯一状态文件；不引入数据库或 JSON 侧车文件。
- 命令：`node runstate.js <init|check|advance|--help>`；失败必须非零退出并打印原因。
- 禁做：不删除文件（删除一律走回收站）、不改 `tasks/` 下已有卡、不装 npm 包。
- **别这样做：Budget 节里不要写散文行。** 任何 `- 标签: 值` 形式的行都会被当作计数行，值必须是 `整数` 或 `整数 / 整数`；散文请写到 `## Notes for the next run`（起因：一次笔误 `abc / 2` 曾让该计数器的预算守卫静默失效，T004 起改为报错）。
- **别这样做：验收标准不要写死现场快照值**（如 `1/2`），要写相对规则（如"达到该文件声明的上限"）——否则换一个预算就与模板默认值冲突（Run #1 已踩）。
- 作用域：本文件只放项目本地规则；开发流程遵循 personal-dev-workflow skill（v0.4.0 有限自治）。
