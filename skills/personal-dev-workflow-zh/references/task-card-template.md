# 任务卡模板（复制到 tasks/NNN-xxx.md）

```markdown
# [任务标题]

- 状态：待执行（待执行 / 执行中 / 待验收 / 已合入 / 打回）
- 优先级：P0/P1/P2
- 创建日期：YYYY-MM-DD
- 关联卡片：（可选）

## 目标
（一句话说清这张卡要交付什么）

## 限制条件 / 禁止事项（必填，最关键）
- （不能改什么：文件/模块/接口/约定）
- （外部副作用默认不授权：发送/发布/删除）

## 验收标准（客观门禁，可执行）
- [ ] （可执行、可验证的标准 1）
- [ ] （标准 2，如：运行 npm test 全部通过）
- [ ] （标准 3，如：页面截图无明显溢出）

## 涉及文件（含影响面：调用者/测试/接口/配置入口）
- `src/...`
- `docs/...`

## 依赖
- 依赖任务卡：tasks/NNN-xxx.md
- 阻塞于：—

## 预期证据（执行器回填）
- [ ] 改动摘要（改了什么、为什么——说不清改了什么，代码不要直接信）
- [ ] diff 已提供
- [ ] 测试结果已提供
- [ ] 截图/演示已提供

## 验收结论（指挥会话回填）
- [ ] 合入 / 打回 / 调整方向
- 备注：
```
