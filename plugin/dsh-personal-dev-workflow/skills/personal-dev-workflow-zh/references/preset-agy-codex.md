# 可选预设：AGY 规划/对抗 → Codex 执行

> 这是个人偏好的示例 preset，不是核心默认。具体模型名属于易变配置，可直接替换。

```text
需求
  → AGYCLI：规划/代码库扫描/任务卡
  → 可选独立对抗评审
  → Codex：按卡执行
  → 独立验证（高风险/大改时）
```

示例配置：

| 阶段 | 工具/模型 | 目标 |
|---|---|---|
| 规划 | AGYCLI + Gemini 3.8 Flash（High） | 快速扫描项目、影响面、拆卡 |
| 执行 | Codex + GPT-6 Luna（Medium） | 按清晰任务卡实现、测试 |
| 评审 | 与执行异构或全新上下文 | 只看任务卡、diff、证据挑错 |

## 使用条件

- 任务足够复杂，规划与执行分离确实减少执行上下文；
- 不要每张小卡都强制“规划 Agent + 对抗 Agent + 执行 Agent + 评审 Agent”；
- 如果任务卡已经清晰且风险低，直接执行更高效。

## 交接格式

交给执行器的内容必须自包含：目标、验收、影响文件、禁止事项、当前事实来源。不要要求执行器重读规划聊天历史。
